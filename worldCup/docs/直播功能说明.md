# 移动端赛事直播功能说明（斗球直播源）

> 上线日期：2026-10-30  
> 数据源：`https://www.dnymrhz.com`（斗球）SSR `__NEXT_DATA__`  
> 对接依据：《斗球直播源对接说明.md》

## 一、功能入口

1. **赛事列表顶部「正在直播」**
   - 展示斗球当前正在直播的**足球**场次（最多 12 场，按人气排序）。
   - 每场合并同一场比赛的多个主播间，点击直接进播放页。
   - 不依赖我方赛事库，所以即使该场比赛已不在投注列表里，也能观看。

2. **赛事卡片「观看直播」**
   - 我方赛事与斗球直播间按「队名 + 开赛时间」匹配成功后，卡片上显示直播入口。
   - 直播中显示红点「直播中」，未开赛/准备中显示「有直播」。
   - 同一场比赛有多个直播间时，播放页可切换线路。

3. **播放页 `pages/match/live`**
   - 支持原画 / 超清 / 高清 / 标清 / 流畅切换，默认高清。
   - 进入页面实时向服务端换取最新 m3u8 链接（`auth_info` 会过期，不缓存播放链）。
   - 播放失败自动重新获取一次；仍失败可点「重新获取」。
   - App/小程序使用 uni-app `<video>`；H5 优先使用本地 `static/js/hls.light.min.js`，Android Chrome 等不支持原生 HLS 的浏览器可正常播放。

## 二、云函数 `user-live`

目录：`kaiyun/uniCloud-alipay/cloudfunctions/user-live/`

| action | 入参 | 说明 |
|---|---|---|
| `list` | `matchIds: string[]` | 我方赛事中可看直播的场次（含直播间列表） |
| `live` | 无 | 当前正在直播的足球场次（列表页顶部） |
| `play` | `matchId?`, `roomId?` | 实时抓取房间页，返回最新 m3u8 播放链 |

约定：

- 所有 action 都需要普通用户 token（`role=user`）。
- `/live` 列表缓存 **2 分钟**；抓取失败时最多回退使用 **10 分钟**内的旧缓存。
- `play` 每次实时请求 `https://www.dnymrhz.com/live/{roomId}`，不缓存播放地址。
- 其它 4xx 不重试；403/5xx/网络错误最多请求 3 次（失败间隔 1s、3s）。
- 站点改版/字段缺失会打 `[user-live]` 错误日志，不会静默返回空数据。

## 三、匹配规则

参考对接说明 3.3 / 3.4：

```
队名归一化后比较：完全相同 0.40 / 一方包含另一方 0.35
开赛时间命中：+0.15（有官方时间按 ±3 小时；无官方时间要求距当前 ≤6 小时）
联赛一致：+0.05
总分 ≥ 0.80 且为唯一最高分才自动匹配
```

- 队名/联赛带常见简称 → 全称映射（如 马竞 ↔ 马德里竞技、巴西甲 ↔ 巴甲）。
- 多候选分数接近时直接跳过，宁可不出直播入口，也不匹配错。
- 斗球直播间没有官方开赛时间时，只在「临近开赛/进行中」窗口内匹配，避免同名球队撞车。

纯逻辑在 `user-live/live-core.js`，单元测试：

```bash
cd kaiyun/uniCloud-alipay/cloudfunctions/user-live
node test-live-core.js
```

当前覆盖解析、归一化、别名、时间窗、歧义、播放链筛选、房间详情等 **50 项断言**。

## 四、部署清单

1. **上传云函数**：新增 `user-live`。
2. **调整超时时间**：uniCloud 控制台 → `user-live` → 配置，超时时间建议 **30 秒**（需要抓取斗球页面并带 2 次重试，默认 3 秒不够）。
3. 不需要定时触发器；不建议对 `user-live` 做 URL 化公开访问（仅 App 内 `callFunction`）。
4. **重新构建 H5**：
   - 新增页面 `pages/match/live.vue`（已在 `pages.json` 注册）。
   - 新增 `static/js/hls.light.min.js`（hls.js 1.5.20 light 版，已放入 `kaiyun/static/js/`）。
   - 确认部署产物包含 `static/js/hls.light.min.js`。
5. App/小程序端无需额外权限；H5 需允许播放跨域 m3u8（源站已返回 `Access-Control-Allow-Origin: *`）。

## 五、常见问题

- **列表里没有「观看直播」入口**
  - 斗球 `/live` 只返回**正在直播**的房间；赛事列表只展示未开赛场次，只有临近开赛（6 小时内）且斗球已开播的场次才会出现入口。
  - 顶部「正在直播」区域不依赖我方赛事，可以先用它验证链路。
- **点击后提示「直播信号暂未开始或已结束」**
  - 主播还没推流或已下播；稍后点「刷新信号」。
- **H5 黑屏**
  - 确认 `static/js/hls.light.min.js` 已部署；代码还会自动回退到 jsDelivr / BootCDN。
  - 检查浏览器控制台是否有 m3u8 403（`auth_info` 过期时重新进入页面即可获取新链接）。
- **匹配不到斗球直播**
  - 查看云函数日志中 `[user-live]` 输出；斗球队名差异较大时，在 `live-core.js` 的 `TEAM_ALIASES` 补充映射。

## 六、风险提示

斗球是非官方聚合直播站，主播源存在版权与稳定性风险；接口/字段也可能随时改版。建议后续切换到正规赛事数据 + 版权直播源。当前实现已做失败降级：直播服务异常不影响赛事列表、赔率与下单。
