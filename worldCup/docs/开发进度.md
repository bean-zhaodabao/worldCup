- 管理端 → 系统配置 新增"赛事展示天数"；`init-db`、`admin-config` 默认配置同步加入 `matchDays`
- **部署**：需重新上传 `user-match`、`init-db`、`admin-config`；管理端重新 build（系统配置页生效）

## 2026-10-23 代理商与短信通知

### 需求口径
- 代理商**只读**：只能查看自己名下用户、订单、佣金，不能创建用户、充值、停用、提现
- 佣金按**下注流水 × 代理独立比例**计算，管理员确认后线下结算
- 用户下注成功后，通过**阿里云短信**通知后台配置的手机号

### 已实现
- **数据模型**
  - `users`：新增 `role=agent`、`agentCode`、`commissionRate`、`commissionBalance`、`paidCommission`、`totalCommission`；用户新增 `agentId`、`agentCodeSnapshot`、`bindTime`
  - `orders`：新增下单时快照 `agentId`、`agentRate`、`commissionStatus`、`commissionAmount`
  - 新增集合：`agent-commission-records`、`agent-commission-settlements`、`agent-wallet-logs`、`sms-config`、`sms-tasks`、`sms-logs`
- **代理端云函数（只读）**
  - `agent-dashboard`：工作台概览、7 天趋势、佣金汇总
  - `agent-user`：名下用户列表/详情
  - `agent-order`：名下订单列表/详情/统计，按订单 `agentId` 快照过滤
  - `agent-commission`：佣金汇总/明细
- **佣金**
  - `agent-commission-job`：每 10 分钟扫描已结算订单，按 `agentId + orderId` 幂等生成佣金
  - 退款/删除订单自动冲销；支持自动/手动确认；结算批次 + 线下支付标记
  - 核心计算在 `agent-commission-job/commission-core.js`，有单元测试
- **管理端**
  - `/agent` 代理商管理、`/agent/:id` 代理详情、`/commission` 佣金结算、`/sms` 短信通知
  - 用户管理支持创建时选择代理、转移代理；订单管理支持按代理筛选
- **移动端**
  - 新增 `pages-agent` 分包：工作台、我的用户、用户详情、用户订单、订单详情、我的佣金、我的
  - 登录按角色跳转，代理端无任何写操作入口
- **短信**
  - `user-order` 下单成功后写入 `sms-tasks`，短信失败不影响订单
  - `sms-job` 每分钟发送，失败 1/5/15 分钟退避重试，最多 3 次
  - `admin-sms` 支持配置、测试发送、日志、失败重发
  - 使用 Node 原生 `https + crypto` 实现阿里云 RPC HMAC-SHA1 签名，无第三方依赖
  - 默认签名/模板/手机号：`甘肃食为天餐饮管理` / `SMS_512616834` / `18298380835`
- **安全修复**
  - 所有 `admin-*` 增加 `role=admin` 校验
  - `user-order` 禁止代理/管理员下单；`user-match`、`user-wallet` 限制普通用户
  - 修复 `admin-user` 充值接口被“创建用户”分支拦截的问题

### 部署要点
- URL 化：`/admin-agent`、`/admin-agent-commission`、`/admin-sms`
- 索引：`agent-commission-records(agentId+orderId)` 唯一；`sms-tasks(orderId+type)` 唯一
- 定时器：`agent-commission-job` 每 10 分钟；`sms-job` 每分钟
- 执行 `init-db` 初始化佣金/短信默认配置
- 短信需在阿里云完成**运营商报备**，签名/模板审核通过并报备成功后才能真正下发

### 维护注意事项
- 历史订单不追溯代理/佣金；只有功能上线后新下的订单计入
- 用户数按当前归属统计；订单/流水/佣金按下单时快照统计，用户转移后两者可能不一致
- 代理端保持只读；如需开放创建用户/充值/提现，需要重新做权限、风控和对账
- 短信接口返回 `OK` 只代表阿里云受理，不代表送达；收不到先看签名运营商报备状态和发送记录
- 密码仍为明文存储，属于既有技术债，后续建议单独做哈希迁移

## 已完成功能（2026-08-20）

### 数据同步（sync-jczq 云函数）
- 赛事列表 upsert（sourceMatchId 幂等，状态单调推进，比分/半场比分/加时点球）
- 未开赛赛事拉取竞彩官方赔率（胜平负/让球胜平负/比分31项/总进球区间/半全场9项）+ 盘口（亚盘/大小球）
- 盘口只取 companyId 8/12/14 三家公司合并：**同盘口去重、每侧取最低水位**（`odds-core.js mergePankou`）
- 水位为香港盘 → 内部存十进制赔率（1+水位）
- 玩法 upsert（sourceKey 幂等），赔率变化 oddsVersion++（移动端 2s 轮询刷新）
- 自动结算引擎：完场按 90 分钟比分判定（走盘退本金/半赢半输/四分盘拆半）、串关全腿完场后结算、取消场次整单退款、中奖自动入账

## 规则基线

- 移动端只展示未开赛赛事；赛事自动上架，管理端可手动上下架
- stop=true 自动停售不可投注；下单以服务端实时赔率为准
- 中奖入账 = 下注额 × 赔率（含本金）；散户下单即扣款，收单账户允许负余额
- 串关 2-8 场、同场不可重复；含取消场次整单退本金
